1 คำนวณคะแนน
ข้อนี้ผมทำฟังก์ชันไว้เช็กคะแนนและคำนวณคะแนนแล้วก็เอาคะแนนไปเทียบเพื่อดูว่าได้เกรดอะไรได้ฝึกใช้ Arrow Function, ค่าเริ่มต้น และ return

2 ทะเบียนนักศึกษา
ข้อนี้ผมสร้างข้อมูลนักศึกษาไว้หลายคนใน Arrayแล้วลองทำฟังก์ชันค้นหาจาก ID และค้นหาตามสาขารวมถึงเช็กว่ามีคนคะแนนไม่ถึง 50 และป้องกันข้อมูลที่ไม่มี

3 สรุปผลการเรียน
ข้อนี้ผมเอาข้อมูลนักศึกษามาหาผลรวมและค่าเฉลี่ยแล้วแยกคนที่ผ่านและนับจำนวนคนตามเกรดโดยได้ลองใช้ map, filter และ reduce แทนการใช้ loop

4 รวมข้อมูล
ข้อนี้ผมเอาข้อมูลชื่อ คะแนน และข้อมูลติดต่อมารวมกันแล้วลองใช้ Spread เพื่อรวมข้อมูลและ Destructuring เพื่อดึงข้อมูลออกมานอกจากนี้ได้ลองเรื่อง Shallow Copy ว่าถ้าแก้ข้อมูลแล้วต้นฉบับจะเปลี่ยนไหม

5 แยกเป็น Module
ข้อนี้ผมทำโค้ดแยกเป็น 3 ไฟล์ให้แยกส่วนเก็บข้อมูล ส่วนคำนวณ และส่วนที่ใช้เรียกโปรแกรมแล้วใช้ export กับ import เพื่อให้แต่ละไฟล์ทำงานร่วมกัน
